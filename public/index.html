Developer Integration & x402 SDK

Integrate x402 client-side in your AI Agent, or protect your backend endpoints in under 3 lines of code.

Client Side: Autonomous Agent Fetch Wrapper

TypeScript / Python

Automatically handles HTTP 402 challenge negotiation, EIP-712 signing, and retry seamlessly:

import { x402Client } from 'synapse402-sdk';

// Initialize with agent private key or session key
const client = new x402Client({
  privateKey: process.env.AGENT_PRIVATE_KEY,
  rpcUrl: 'https://sepolia.base.org'
});

// Automatic x402 handling:
// 1. Sends request -> gets 402 Challenge
// 2. Signs EIP-712 payment voucher autonomously
// 3. Retries with X-Payment header -> returns 200 data!
const response = await client.fetch('https://api.synapse402.org/api/x402/intel/deepseek-financial?symbol=NVDA');
const intelligence = await response.json();
console.log('Unlocked Quant Signal:', intelligence.data);

Server Side: 1-Line Endpoint Protection

Express / Node.js

Monetize any route by adding the x402Guard middleware:

const express = require('express');
const { x402Guard } = require('synapse402/middleware');

const app = express();

// Guard route with 0.005 USDC paywall
app.get('/api/premium-ai-tool', 
  x402Guard({ 
    amount: 0.005, 
    payee: '0xYourWalletAddress...',
    name: 'Premium AI Tool'
  }), 
  (req, res) => {
    // Access unlocked only after x402 settlement!
    res.json({ message: 'Premium compute served!', receipt: req.x402.receipt });
  }
);
